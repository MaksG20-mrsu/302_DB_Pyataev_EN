# Task01

## Структура файлов

- `ratings.csv` — оценки пользователей (userId, movieId, rating, timestamp).
- `movies.csv` — информация о фильмах.
- `tags.csv` — теги пользователей.
- `users.txt` — данные пользователей.
- `genres.txt` — список жанров.
- `occupation.txt` — список профессий.
- `ratings_count.txt` — минимальный и максимальный userId с количеством строк.
- `sqlite.txt` — версия SQLite и доступные режимы вывода.
